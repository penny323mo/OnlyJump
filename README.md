# OnlyJump · 失物天台

[手機或電腦直接試玩](https://penny323mo.github.io/OnlyJump/)

由士多天台出發，踩過腳凳、波鞋、唱盤、玩具跑車、繫纜柱同吊臂鋼樑，經失物招領枱進入晾衣場，踩上木衣夾、鋁摺梯同弧形太陽傘。主線共 24 個落腳點，最高約 20.7 米。頭幾跳可以用普通跳，先跳上正前方嘅絲絨腳凳，再跳去木茶几。之後經皮喼同波鞋跳上錄音帶，再踩木喇叭去唱盤。到古董相機之後，滑板同繫纜柱之間就要留意助跑距離同落腳角度。跌落時可以企返喺下面任何接得住嘅物件，繼續爬。跌穿整座天台先會返起點。落穩錄音帶、玩具跑車、失物招領枱或者終點，畫面會標示今局到過嘅最高 Checkpoint。跌返下層會保留標記，重開一局會清除。

「距頂」按腳底同終點嘅垂直高度差即時更新，跌落下層時會加返。最高落腳紀錄按腳底企穩嘅高度計，精確到 0.1 米。沿斜桿行上高處同搭吊籃升高都會更新紀錄，並儲存喺目前瀏覽器。

首次踩上天台太陽傘會記低完賽時間、起跳同跌落次數。再玩時，首次踩返最快嗰局經過嘅物件，計時器下方會短暫顯示快慢差距。兩條路喺電子琴會合，就可以知道行捲尺捷徑慳咗幾多時間。暫停期間會停錶。

| 操作 | 手機 | 電腦 |
| --- | --- | --- |
| 移動 | 左半屏落指再拖動，放手回中 | WASD 或方向鍵 |
| 跳躍 | 輕撳跳躍 | 空白鍵 |
| 助跑 | 按住加速，滑落跳掣即起跳。想接住跑跳，同一隻拇指滑返上加速，再滑落跳掣。放手就解除加速 | 按住 Shift |
| 環視 | 喺右半屏空位掃動。由轉鏡改做雙指縮放後，放開第二指，原本轉鏡嗰隻拇指可以接住掃 | 拖曳滑鼠，或按 Q / E 旋轉 |
| 鏡頭遠近 | 喺畫面空位用兩指張開拉近、合埋拉遠，同邊或跨中線都得。拇指按住搖桿嗰陣，可以用另外兩隻手指縮放 | 網頁版支援多點觸控螢幕 |
| 對準下一件物件 | 撳「對準目標」 | F |
| 揀分岔方向 | 有分岔時撳左上「⇄ 揀路」 | 點選「⇄ 揀路」，Godot 桌面版用 Tab |
| 暫停 | 右上角暫停掣 | P 或 Esc |

手機遊戲切去背景或轉屏時會停低。返嚟可以先轉鏡、雙指校遠近，或者按住加速準備。推搖桿、撳跳掣，或者撳右上「繼續」，角色同移動中嘅物件先會接住郁。

主畫面可以揀天台速遞員、菠蘿油俠、鹹魚仔、雪糕筒工頭或短手暴龍。五款角色共用跳躍、腳掌同扶邊物理，選擇會記住。

正式關卡有十個分岔位。起點嘅迷你彈床彈向膽機電視，高層嘅斜頭彈簧彈向鋁摺梯。落腳踩中細金圈，角色會屈膝壓低彈面，回彈時自動起跳。由高處落腳會壓深啲，彈力有上限。踩外圈可以企穩，再自己揀方向跳。唱盤附近可以搭旋轉扇葉轉去古董相機旁邊。放開搖桿，雙腳同身體會跟住扇葉轉，鏡頭留喺你揀嘅方向。喺葉尖起跳會帶住側向速度。晾衣場可以沿圓桿行、等吊籃埋站，或者搏鬆脫木板橫過去。踩上舊抽屜之後，佢會沿路軌滑出兩截，露出紅色擋塊。裂紋木板就會由固定嗰端向下傾，板頭愈低，留畀你起跳嘅時間就愈少。木板下面張被單可以接人，再由洗衣機接返主線。企穩喺分岔位撳「揀路」，可以睇到分支嘅跳法同出口。吊籃會提示近站踏板有冇放平，抽屜同木板跌咗會提示等佢返位。起跳後提示會收起，撳「返主線」可以再對準主路。

第 6 站錄音帶可以轉去發條捲尺。跳上尺殼，踩住銀色尺頭再放開搖桿，就會隨尺帶伸出去。尺口露出紅段時，向電子琴推前兼撳跳，可以借力越過手提音響同唱盤。留喺尺頭會原路收返，行返上尺殼再踩就可以重試。[睇捲尺起跳示範](https://penny323mo.github.io/OnlyJump/tape-measure.mp4)

第 8 站嘅黑膠唱片會順時針轉。放開搖桿，雙腳會隨碟面嗰張米色貼紙一齊兜圈。碟中央郁得少，行近碟邊再起跳，就會帶住當刻嘅側向速度。想企定瞄準，可以行返出木邊。主線跳去電子琴，撳「揀路」可以轉去大風扇。[睇手機實玩唱盤跳扇葉](https://penny323mo.github.io/OnlyJump/turntable.mp4)

第 9 站可以用腳彈電子琴。沿白鍵前端由左行到右，會由低 C 彈到高 C。行近後排，五粒黑鍵會加埋中間嘅半音。踩中嘅鍵會壓低同着色，熄咗聲都可以喺琴面睇到音名。行返上旋鈕旁邊嘅琴殼，就可以停低瞄準古董相機。[睇暴龍踩琴鍵嘅有聲實玩](https://penny323mo.github.io/OnlyJump/polytone.mp4)

由第 11 站滑板跳向玩具車，跳歪去車身外側，有機會跌入下面條橙色玩具飛車滑道。落槽後會順住斜度滑，反推搖桿可以減速。向棋盤格嗰端助跑，喺上斜位對住滑板撳跳，就可以接返第 11 站。[睇短手暴龍滑槽救場慢鏡](https://penny323mo.github.io/OnlyJump/toy-track.mp4)

皮喼旁邊個舊抽屜鬆脫嗰陣，可以望落去搵紅黃間條嘅士多布篷。落喺篷面就可以轉向木茶几，再跳上電視。由抽屜外沿滑出去，木茶几亦可以接住你。

第 19 站熨衫板撳「揀路」會望向吊籃埋站嘅位置。見到左前角塊黃邊踏板攤平，可以短跳上去，再行入籃。開車嗰陣踏板會向下摺，企喺板尖會跣落去。上籃後撳一次「對準目標」就可以預先瞄準晾衫架，到對岸再起跳。[睇吊籃上落示範](https://penny323mo.github.io/OnlyJump/laundry-lift.mp4)

喺第 10 站古董相機撳「揀路」可以望向黃色水平尺。跳上近端，等另一端翹起，再沿尺面助跑，踩到兩條紅刻度附近就跳去第 13 站碼頭繫纜柱。如果企喺遠端等，隻腳會壓低尺頭；由唱盤嗰邊踏空，有機會跌返第 8 站再爬。[睇水平尺捷徑同跌落唱盤示範](https://penny323mo.github.io/OnlyJump/spirit-level.mp4)

去到第 13 站碼頭繫纜柱，撳「揀路」對準鐘擺最低點。等個銅擺返過嚟，跳上圓頂，放手搭住佢擺向吊臂鋼樑。喺銅擺上撳「對準目標」可以預先瞄準出彎方向，到高位再助跑跳出去。錯過銅擺有機會跌到手提音響；喺左端踏空，下面嘅黑膠唱盤亦可以接人。[睇手機版鐘擺捷徑](https://penny323mo.github.io/OnlyJump/pendulum-clock.mp4)

沿途有四件道具，帶薄荷綠浮空菱框。行近會見到效用同使用限制。跳躍時提示會盡量跟喺道具同一邊，避開角色、菱框、操作掣同預計落點十字。移開時有條幼線指返件道具。執起新道具會取代身上嗰件，每局每件可以執一次。

| 道具 | 用法 |
| --- | --- |
| 黃鴨仔 | 15 秒內，每次離地後可以再撳跳補跳一次，合共最多補跳三次。推住方向做前空翻，放開方向就原地自轉。 |
| 發條匙 | 執到先裝備，撳跳點火後有 3 秒推力，最多升約 2.5 米，用搖桿揀飛行方向。 |
| 飛天襪 | 6 秒內減慢下墜，可以飄返下面嘅物件。青白十字會按剩餘時間，預計回復正常下墜後嘅落點。 |
| 袖珍飛爪 | 喺士多布篷執起，撳「對準目標」望向舊電視嘅銅環。向前跳，銅環亮起時再撳同一個跳掣收索，有機會越過茶几、落到電視頂。飛爪只可以扣環一次，射程 3.35 米，出爪太遲仍然會跌短。 |

[睇 iPhone Duo 外屏飛爪操作示範](https://penny323mo.github.io/OnlyJump/awning-grapple.mp4)

手機暫停時可以揀右手按掣大小。橫屏有足夠空間時可以即場預覽，選擇會儲存喺目前瀏覽器。

跌落腳凳係一聲悶響，木茶几有短促嘅木響，鋼樑會有金屬尾音。落差愈大，角色落地時屈膝愈深。雙腳一掂地就可以再跳。

iPhone Duo 可以用外屏、展開嘅內屏，或者 Safari 雙視窗玩。摺合或展開會保留當局進度，重新落指就可以繼續控制。Safari 工具列收起時，按住嘅方向同加速會繼續生效。

喺「暫停 → 遊戲選項 → 畫風」可揀「一般」或「油畫」，下次開遊戲會記住。

下一站嘅物件名喺左上角。標示下一站嘅橙圈預設收埋，可喺「暫停 → 遊戲選項」開啟，預計落點亦可以獨立開關。助跑時，青白十字會標示而家起跳嘅預計落點。如果只有鞋邊夠到，標記會喺掂到嘅位置變成黃箭嘴，指向有位企嗰邊。[睇舊版梳化示範邊緣同坐墊嘅落點分別](https://penny323mo.github.io/OnlyJump/landing-marks.webp)

離地後會按你嘅速度同方向更新。跳向走索吊籃時，十字會跟住籃底或者攤開嘅踏板移動，標出按而家速度會踩中嘅位置。吊籃開走之後，如果條跳躍路線會落到下層，十字可以標喺下面嘅物件。踏板摺起、落點鬆脫或者前面有牆擋住時，十字會收起。原地撳跳會垂直起跳，推住方向起跳會向前。起跳沿用助跑慣性，空中放手會繼續向前。左手搖桿只控制移動。開揚位置微調腳步時鏡頭會定住，行遠先會平移。右手掃動可以轉鏡，亦可以撳「對準目標」望向下一站。靠近窄邊會減速，放開搖桿就收腳。腳掌部分伸出鋼樑時仍然可以企穩。

企喺三角紙盒同電纜轆上，兩隻鞋會跟住各自腳下嘅斜度，膝頭可以一高一低。喺窄邊只夠一隻腳踩實時，角色會將重心移向嗰邊。[睇站姿對照](https://penny323mo.github.io/OnlyJump/slope-stance.webp)

慢行跣出窄邊時，即刻將搖桿拉返向原本嗰件物件。如果雙手仲夠到上沿、上面有位企，今次失足有一次 70% 機會捉返。跳掣變成「撐上」就可以爬返去。加速衝出邊會更快離開伸手範圍。[睇鋼樑回身扶邊慢鏡](https://penny323mo.github.io/OnlyJump/girder-recovery.mp4)

原作點樣用圓喉、路軌同斜面改變落腳方式，可以睇[《Only Up!》玩法考察](docs/only-up-reference.md)。

跳短少少、向住物件邊沿跌落時，如果雙手掂到上沿而上方有位企，每跳有一次 70% 機會捉住。捉穩後沿住邊推搖桿，角色會一隻手接一隻手橫移，去到盡頭就停。撳右手「撐上」掣或空白鍵，會喺新位置爬上去。想跌去下層，就向離開物件嘅方向拉住搖桿約 0.2 秒。搖桿放返中間，等一陣就會自動爬。撐上唔會消耗二段跳。[睇短手暴龍沿鋼樑橫移](https://penny323mo.github.io/OnlyJump/girder-traverse.mp4) · [睇 iPhone Duo 撳掣示範](https://penny323mo.github.io/OnlyJump/duo-pull-up.mp4) · [睇茶几扶邊近鏡](https://penny323mo.github.io/OnlyJump/ledge-grab.mp4)

喺木茶几底、晾衫架或者裂紋木板底轉鏡，鏡頭會沿住你揀嘅方向升高或降低，等你睇到隻腳同落腳位。離開遮擋就會逐步返到原本視角。手動環視亦會避開前景物件。

喺接人被單上面，可以企近裂紋木板嘅側邊，面向木板、放開方向桿再原地跳。雙手夠到就有同一次扶邊機會。捉住扇葉時身體會跟住轉，吊籃移動期間亦可以一路扶住爬上去。木板如果中途鬆脫，角色會放手跌返落去。

## 本機開發

使用標準版 Godot 4.7.2 開啟 `project.godot`，按 F5 執行專案。桌面版由 Enter 開始。

安裝相同版本的 Web export templates 後，可從專案根目錄匯出並試玩。

```sh
./scripts/export-web.sh
python3 -m http.server 8137 --bind 127.0.0.1 --directory build/web
```

開啟 <http://127.0.0.1:8137/>。若 Godot 未加入 PATH，可將 `GODOT_BIN` 設為 Godot 執行檔路徑。

## 部署與驗證

推送至 main 會觸發 GitHub Actions，下載指定版本的 Godot、核對 SHA-256、匯出單執行緒 WebGL 2 版本、以遊戲物理驗證整段路線，再發佈至 GitHub Pages。可在 Actions 手動重新部署。

```sh
godot --headless --import
godot --headless --fixed-fps 60 --script tests/route.gd
godot --headless --fixed-fps 60 --script tests/stance.gd
godot --headless --fixed-fps 60 --script tests/branches.gd
godot --headless --fixed-fps 60 --script tests/lift.gd
godot --headless --fixed-fps 60 --script tests/tape_measure.gd
godot --headless --fixed-fps 60 --script tests/pendulum.gd
godot --headless --fixed-fps 60 --script tests/spirit_level.gd
godot --headless --fixed-fps 60 --script tests/grips.gd
godot --headless --fixed-fps 60 --script tests/records.gd
godot --headless --fixed-fps 60 --script tests/camera.gd
godot --headless --fixed-fps 60 --script tests/grapple.gd
```

本機裝有 Playwright 同 WebKit 時，可以開住上面嘅本機伺服器，執行 `node tests/iphone-duo.cjs`。測試會用短手暴龍跑跳上腳凳，再喺同一局切換十組 iPhone Duo 視窗尺寸，逐次驗證雙指操作同跳躍次數。[WebKit 公布嘅 Safari 尺寸表](https://webkit.org/blog/18486/webkit-features-for-safari-27-1/#viewport-sizes)

執行 `node tests/scenery-motion.cjs` 可以重播外屏同內屏嘅慢速轉鏡。測試會先確認六個街景取樣區喺定鏡時冇變化，再逐幀量度轉鏡時嘅像素跳變。

執行 `node tests/startup.cjs` 可以分別模擬四種遊戲檔案下載失敗、斷線同慢網絡，驗證撳「重新載入」或繼續等之後入到場並完成第一跳。

`node tests/pickup-hints.cjs` 會先喺外屏原地跳，量度黃鴨仔同標籤之間嘅相對移動，檢查落點十字有冇被遮住。之後會喺十組 iPhone Duo 視窗尺寸用加大按掣同浮動搖桿轉鏡，再執起黃鴨仔驗證提示消失同二段跳次數。
