# OnlyJump · 失物天台

[手機或電腦直接試玩](https://penny323mo.github.io/OnlyJump/)

由士多天台出發，踩過梳化、波鞋、唱盤、玩具跑車、繫纜柱同吊臂鋼樑，經失物招領枱進入晾衣場，踩上木衣夾、鋁摺梯同弧形太陽傘。主線共 24 個落腳點，最高約 20.7 米。跌落時可以企返喺下面任何接得住嘅物件，繼續爬。跌穿整座天台先會返起點。最高落腳紀錄按腳底企穩嘅高度計，精確到 0.1 米。沿斜桿行上高處同搭吊籃升高都會更新紀錄，並儲存喺目前瀏覽器。

| 操作 | 手機 | 電腦 |
| --- | --- | --- |
| 移動 | 左半屏落指再拖動，放手回中 | WASD 或方向鍵 |
| 跳躍 | 輕撳跳躍 | 空白鍵 |
| 助跑 | 按住跳掣上方嘅加速掣，同一隻拇指滑落跳掣即起跳 | 按住 Shift |
| 環視 | 喺右半屏空白位置掃動 | 拖曳滑鼠，或按 Q / E 旋轉 |
| 自動跟鏡 | 撳「追蹤鏡頭」切換 | C |
| 對準下一件物件 | 撳「對準目標」 | F |
| 揀分岔方向 | 有分岔時撳左上「⇄ 揀路」 | 點選「⇄ 揀路」，Godot 桌面版用 Tab |
| 暫停 | 右上角暫停掣 | P 或 Esc |

主畫面可以揀天台速遞員、菠蘿油俠、鹹魚仔、雪糕筒工頭或短手暴龍。五款角色共用跳躍、腳掌同扶邊物理，選擇會記住。

正式關卡有七個分岔位。起點嘅迷你彈床彈向膽機電視，高層嘅斜頭彈簧彈向鋁摺梯。落腳踩中細金圈，角色會屈膝壓低彈面，回彈時自動起跳。由高處落腳會壓深啲，彈力有上限。踩外圈可以企穩，再自己揀方向跳。唱盤附近可以搭旋轉扇葉轉去古董相機旁邊。放開搖桿，雙腳同身體會跟住扇葉轉，鏡頭留喺你揀嘅方向。喺葉尖起跳會帶住側向速度。晾衣場可以沿圓桿行、等吊籃埋站，或者搏鬆脫木板橫過去。木板同舊抽屜受力後會搖，跟住跌。木板下面張被單可以接人，再由洗衣機接返主線。揀路只會改提示同鏡頭，你隨時可以自行轉線。

皮喼旁邊個舊抽屜鬆脫嗰陣，可以望落去搵紅黃間條嘅士多布篷。落喺篷面就可以轉向木茶几，再跳上電視。布篷只伸到抽屜下面一部分，行到抽屜外沿仍然有機會跌返街面。

沿途有四件道具，帶薄荷綠浮空菱框。行近會見到效用同使用限制。提示會避開角色、菱框同操作掣，移開時有條幼線指返件道具。執起新道具會取代身上嗰件，每局每件可以執一次。

| 道具 | 用法 |
| --- | --- |
| 黃鴨仔 | 15 秒內，每次離地後可以再撳跳補跳一次，合共最多補跳三次。推住方向做前空翻，放開方向就原地自轉。 |
| 發條匙 | 執到先裝備，撳跳點火後有 3 秒推力，最多升約 2.5 米，用搖桿揀飛行方向。 |
| 飛天襪 | 6 秒內減慢下墜，可以飄返下面嘅物件。 |
| 袖珍飛爪 | 喺士多布篷執起，撳「對準目標」望向舊電視嘅銅環。向前跳，銅環亮起時再撳同一個跳掣收索，有機會越過茶几、落到電視頂。飛爪只可以扣環一次，射程 3.35 米，出爪太遲仍然會跌短。 |

[睇 iPhone Duo 外屏飛爪操作示範](https://penny323mo.github.io/OnlyJump/awning-grapple.mp4)

手機暫停時可以揀右手按掣大小。橫屏有足夠空間時可以即場預覽，選擇會儲存喺目前瀏覽器。

iPhone Duo 可以用外屏、展開嘅內屏，或者 Safari 雙視窗玩。摺合或展開會保留當局進度，重新落指就可以繼續控制。Safari 工具列收起時，按住嘅方向同加速會繼續生效。

喺「暫停 → 遊戲選項 → 畫風」可揀「一般」或「油畫」，下次開遊戲會記住。

下一站嘅物件名喺左上角。標示下一站嘅橙圈預設收埋，可喺「暫停 → 遊戲選項」開啟，預計落點十字亦可以獨立開關。助跑時，青白十字會標示而家起跳嘅預計落點。離地後會按你嘅速度同方向更新，前面有牆擋住、落點會郁或鬆脫，或者暫時冇可企嘅落點，十字就會收起。原地撳跳會垂直起跳，推住方向起跳會向前。起跳沿用助跑慣性，空中放手會繼續向前。追蹤鏡頭預設開啟，落地移動時會跟到身後，離地時保持起跳方向。靠近窄邊會減速，放開搖桿就收腳。腳掌部分伸出鋼樑時仍然可以企穩。

原作點樣用圓喉、路軌同斜面改變落腳方式，可以睇[《Only Up!》玩法考察](docs/only-up-reference.md)。

跳短少少、向住物件邊沿跌落時，如果雙手掂到上沿而上方有位企，每跳有一次 70% 機會捉住。成功時右手跳掣會變成「撐上」。撳一下可以早啲爬，電腦用空白鍵。放手等一陣亦會自動爬。撐上唔會消耗二段跳。[睇 iPhone Duo 撳掣示範](https://penny323mo.github.io/OnlyJump/duo-pull-up.mp4) · [睇茶几扶邊近鏡](https://penny323mo.github.io/OnlyJump/ledge-grab.mp4)

喺梳化背、晾衫架或者裂紋木板底轉鏡，鏡頭會沿住你揀嘅方向升高或降低，等你睇到隻腳同落腳位。離開遮擋就會逐步返到原本視角。手動環視同自動跟鏡都會避開前景物件。

喺接人被單上面，可以企近裂紋木板嘅側邊，面向木板、放開方向桿再原地跳。雙手夠到就有同一次扶邊機會。捉住扇葉時身體會跟住轉，吊籃移動期間亦可以一路扶住爬上去。木板如果中途鬆脫，角色會放手跌返落去。

## 本機開發

使用標準版 Godot 4.7.2 開啟 `project.godot`，按 F5 執行專案。桌面版由 Enter 開始。

安裝相同版本的 Web export templates 後，可從專案根目錄匯出並試玩。

```sh
./scripts/export-web.sh
python3 -m http.server 8137 --bind 127.0.0.1 --directory build/web
```

開啟 <http://127.0.0.1:8137/>。若 Godot 未加入 PATH，可將 `GODOT_BIN` 設為 Godot 執行檔路徑。

## 部署與驗證

推送至 main 會觸發 GitHub Actions，下載指定版本的 Godot、核對 SHA-256、匯出單執行緒 WebGL 2 版本、以遊戲物理驗證整段路線，再發佈至 GitHub Pages。可在 Actions 手動重新部署。

```sh
godot --headless --import
godot --headless --fixed-fps 60 --script tests/route.gd
godot --headless --fixed-fps 60 --script tests/branches.gd
godot --headless --fixed-fps 60 --script tests/grips.gd
godot --headless --fixed-fps 60 --script tests/records.gd
godot --headless --fixed-fps 60 --script tests/camera.gd
godot --headless --fixed-fps 60 --script tests/grapple.gd
```

本機裝有 Playwright 同 WebKit 時，可以開住上面嘅本機伺服器，執行 `node tests/iphone-duo.cjs`。測試會用短手暴龍跑跳上梳化，再喺同一局切換十組 iPhone Duo 視窗尺寸，逐次驗證雙指操作同跳躍次數。[WebKit 公布嘅 Safari 尺寸表](https://webkit.org/blog/18486/webkit-features-for-safari-27-1/#viewport-sizes)

執行 `node tests/scenery-motion.cjs` 可以重播外屏同內屏嘅慢速轉鏡。測試會先確認六個街景取樣區喺定鏡時冇變化，再逐幀量度轉鏡時嘅像素跳變。

`node tests/pickup-hints.cjs` 會喺十組 iPhone Duo 視窗尺寸用加大按掣同浮動搖桿轉鏡，再實際執起黃鴨仔，驗證標籤位置、消失時機同二段跳次數。
