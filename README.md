# OnlyJump · 失物天台

[手機或電腦直接試玩](https://penny323mo.github.io/OnlyJump/)

由士多天台出發，踩過梳化、波鞋、唱盤、玩具跑車、繫纜柱同吊臂鋼樑，經 18 跳登上約 15.6 米高的失物招領枱。落差大時仍有機會踩返下層物件。最高落腳高度儲存在目前瀏覽器。

| 操作 | 手機 | 電腦 |
| --- | --- | --- |
| 移動 | 左半屏落指再拖動，放手回中 | WASD 或方向鍵 |
| 跳躍 | 輕撳跳躍 | 空白鍵 |
| 助跑 | 按住跳掣上方嘅加速掣，同一隻拇指滑落跳掣即起跳 | 按住 Shift |
| 環視 | 喺右半屏空白位置掃動 | 拖曳滑鼠，或按 Q / E 旋轉 |
| 自動跟鏡 | 撳「追蹤鏡頭」切換 | C |
| 對準下一件物件 | 撳「對準目標」 | F |
| 暫停 | 右上角暫停掣 | P 或 Esc |

手機暫停時可以揀右手按掣大小。橫屏有足夠空間時可以即場預覽，選擇會儲存喺目前瀏覽器。

下一站嘅物件名喺左上角。標示下一站嘅橙圈預設收埋，可喺「暫停 → 提示選項」開啟，預計落點十字亦可以獨立開關。助跑時，青白十字會標示而家起跳嘅預計落點。離地後會按你嘅速度同方向更新，前面有牆擋住或者暫時冇可企嘅落點，十字就會收起。原地撳跳會垂直起跳，推住方向起跳會向前。起跳沿用助跑慣性，空中放手會繼續向前。追蹤鏡頭預設開啟，落地移動時會跟到身後，離地時保持起跳方向。靠近窄邊會減速，放開搖桿就收腳。腳掌部分伸出鋼樑時仍然可以企穩。

原作點樣用圓喉、路軌同斜面改變落腳方式，可以睇[《Only Up!》玩法考察](docs/only-up-reference.md)。

跳短少少、向住物件邊沿跌落時，如果雙手掂到上沿而上方有位企，每跳有一次 70% 機會捉住。成功會短暫吊住，再自動撐上去，全程毋須額外撳掣。[睇茶几扶邊示範](https://penny323mo.github.io/OnlyJump/ledge-grab.mp4)

## 本機開發

使用標準版 Godot 4.7.2 開啟 `project.godot`，按 F5 執行專案。桌面版由 Enter 開始。

安裝相同版本的 Web export templates 後，可從專案根目錄匯出並試玩。

```sh
./scripts/export-web.sh
python3 -m http.server 8137 --bind 127.0.0.1 --directory build/web
```

開啟 <http://127.0.0.1:8137/>。若 Godot 未加入 PATH，可將 `GODOT_BIN` 設為 Godot 執行檔路徑。

## 部署與驗證

推送至 main 會觸發 GitHub Actions，下載指定版本的 Godot、核對 SHA-256、匯出單執行緒 WebGL 2 版本、以遊戲物理驗證整段路線，再發佈至 GitHub Pages。可在 Actions 手動重新部署。

```sh
godot --headless --import
godot --headless --fixed-fps 60 --script tests/route.gd
```

角色、城市及部分道具的作者、授權及改動記錄載於[模型鳴謝](web/credits.txt)。
