# 失物天台物件位置覆核

由士多天台到太陽傘，共 25 個主線站位（包括起點）、14 個分支或救援物件、4 件道具。逐站用遊戲鏡頭查看，並用 Godot 角色實際起跳、落腳、搭吊籃同跌落下層。

| 高度 | 主線落腳次序 | 分支、接人位同道具 |
| --- | --- | --- |
| 0–4.7 m | 天台 → 絲絨腳凳 → 木茶几 → 膽機電視 → 皮喼 → 波鞋鞋底 → 錄音帶 | 起點左側嘅迷你彈床可以彈去電視，黃鴨仔放喺彈床邊。皮喼旁嘅鬆脫抽屜通往錄音帶，下面嘅布篷同茶几可以接人。落喺布篷可以執飛爪，借電視天線爬返上去。 |
| 4.7–10.2 m | 錄音帶 → 手提音響旁嘅喇叭 → 黑膠唱盤 → 電子琴 → 古董相機 → 滑板 → 玩具跑車 | 發條捲尺通往電子琴。大風扇通往相機，發條匙跟住扇葉轉。翹翹水平尺可以借勢跳到繫纜柱。玩具滑道接得住部分失足路線，可以沿彎位滑返去滑板。 |
| 10.2–15.6 m | 玩具跑車 → 繫纜柱 → 貨櫃 → 橫放電纜轆 → 吊臂鋼樑 → 三角紙盒 → 失物招領枱 | 掛鐘銅擺擺向鋼樑，舊掛鐘頂可以接返失物招領枱。錯過擺幅亦有機會跌返唱盤或音響。 |
| 15.6–20.7 m | 失物招領枱 → 熨衫板 → 木衣夾 → 洗衣機 → 晾衫架 → 鋁摺梯 → 太陽傘 | 可揀斜晾衫桿去洗衣機、走索吊籃去晾衫架，或者用斜頭彈簧去摺梯。洗衣機旁嘅裂紋木板可以直跳太陽傘。踏遲咗，下面有被單接人，亦有飛天襪可以執。 |

## 調位結果

- 開場右邊張梳化同腳凳原本共用第一站進度。移走梳化之後，正前方腳凳係第一跳，左側彈床有獨立目的地。天台邊同腳凳之間有 33 cm 水平空位。
- 貨櫃稍為移開，櫃邊同電纜轆嘅水平空位由 13 cm 增至 33 cm。兩者高度相差 92 cm，仍然要起跳。
- 吊籃遠站向外移 82 cm，太陽傘亦移離籃架。去程、回程、踏板打開同收起都檢查過。搭籃跳晾衫架、經摺梯登頂、由裂紋木板跳太陽傘三條路都跳通。
- 抽屜鬆脫後避開茶几同電視。木板跌到被單就消失，騰出接人位置。道具菱形框嘅下端收短，浮動時同彈床、被單之間有空位。士多下層外牆亦收返入行人路旁邊，避開街燈。

## 驗證範圍

用實際渲染器讀取模型，按每秒 60 格取樣 12.8 秒，共 769 組姿勢。檢查主線、分支、道具同路線附近嘅街景。另將木板跌落同吊籃行車嘅時間錯開比較。掛鐘擺桿同鐘殼喺轉軸接合。由上往下投影時，鋼樑同紙盒，以及上層傢俬嘅腳同下層落腳面，部分輪廓會重合；立體模型之間有空位。

持續整合會執行 [物件擺位測試](../tests/course_layout.gd)、[開場普通跳](../tests/opening.gd) 同 [主線登頂](../tests/route.gd)。另外有獨立測試覆蓋彈床、扇葉、吊籃、木板鬆脫、道具同跌落救援。測試涵蓋指定跳法、鏡頭同運動取樣；玩家手動環視時，前後景仍然可以互相遮擋。
